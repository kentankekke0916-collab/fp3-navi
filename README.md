# FP3級 独学ナビ

FP3級の独学に使える無料の学習ツール。スマホのブラウザで使えます。

https://kentankekke0916-collab.github.io/fp3-navi/

- 試験日から逆算した学習プラン
- 6分野180問のオリジナル問題（○×・三択）と、間違えた問題の解き直し
- 本番形式の模擬試験（60問・120分）
- 分野別の正答率チェック

学習の記録は使っている端末のブラウザにだけ保存されます。問題はすべてオリジナルで、2026年10月時点の制度にもとづいて作成しています。
